# Реестр учёта первичных документов — версия без сервера

Один файл — `index.html`. Никакого Python, `pip install` или `python app.py`
не нужно. Работает через File System Access API прямо в браузере.

## Важное ограничение

File System Access API поддерживают **только Chrome, Edge и Opera**
(десктоп). В Firefox и Safari эта версия не заработает — там придётся
пользоваться версией на Flask.

## Как запустить

1. Откройте `index.html` двойным кликом — он откроется в браузере по
   умолчанию.
2. Если он открылся не в Chrome/Edge — щёлкните правой кнопкой →
   «Открыть с помощью» → выберите Chrome или Edge.
3. Нажмите **«Выбрать папку»** и укажите папку, где хотите хранить реестр
   (например, ту же, где лежит `index.html`, или отдельную).
4. Готово — дальше всё сохраняется прямо в эту папку:
   - `registry.json` — сам реестр (документы, стадии, история);
   - файлы вложений — плоско, рядом, под именами, которые вы задаёте при
     загрузке.

При следующем открытии браузер может попросить заново подтвердить доступ
к папке (это его политика безопасности) — просто нажмите «Подтвердить
доступ к папке».

## Если браузер не даёт доступ к папке при открытии файла напрямую

В редких случаях (некоторые версии/настройки Chrome) двойной клик по
файлу может не дать открыть диалог выбора папки. Тогда решение —
поднять простейший локальный сервер без всякой установки (модуль
`http.server` есть в Python из коробки, ничего ставить не нужно):

```bash
cd путь/к/папке/с/index.html
python -m http.server
```

и открыть в браузере `http://localhost:8000`. Это не "сайт" в смысле
публикации — сервер слушает только ваш компьютер.

## Как это устроено

- Всё состояние (документы, стадии, история переходов) хранится в одном
  JSON-файле `registry.json` в выбранной папке.
- При добавлении файла браузер копирует содержимое выбранного файла в
  новый файл на диске с именем `{ваше название} v{номер версии}.{расширение}`
  — прямо в корне выбранной папки, без вложенных подпапок.
- При переводе документа на следующую стадию можно сразу приложить новую
  версию файла — старая версия при этом не трогается и не перезаписывается.
- Удаление версии файла — единственное действие, которое реально убирает
  файл с диска (кнопка «Удалить» у конкретной версии).
- Никакого сервера, интернета или отправки данных куда-либо не происходит:
  всё остаётся на вашем компьютере, в выбранной вами папке.

## Ограничения по сравнению с версией на Flask

- Работает только в Chrome/Edge/Opera.
- Разрешение на папку иногда приходится подтверждать заново при перезапуске
  браузера.
- Нет полноценной многопользовательской работы (впрочем, вы указали, что
  реестром пользуетесь только вы один).
