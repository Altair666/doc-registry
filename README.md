# Реестр учёта первичных документов

Локальное приложение без сервера и установки — набор статических файлов,
работает через File System Access API прямо в браузере (Chrome / Edge / Opera).

## Структура проекта

```
index.html          — голая разметка (структура страницы, без стилей и логики)
css/style.css        — все стили
js/config.js          — конфигурация по умолчанию (виды документов+префиксы, контрагенты)
js/storage.js          — доступ к папке на диске, чтение/запись registry.json и config.json
js/app.js               — рендеринг интерфейса и обработка событий
```

## Как запустить

1. Откройте `index.html` в Chrome или Edge (двойным кликом, либо через
   «Открыть с помощью»).
2. Нажмите **«Выбрать папку»** и укажите папку для хранения данных —
   например, ту же, где лежат файлы приложения, или отдельную.
3. Готово. Всё сохраняется прямо в эту папку:
   - `registry.json` — документы, стадии, история переходов;
   - `config.json` — справочники: виды документов (с префиксами) и контрагенты;
   - сами вложения — плоско, рядом, без подпапок.

При повторном открытии браузер может попросить заново подтвердить доступ к
папке — нажмите «Подтвердить доступ к папке».

Если открытие напрямую (`file://`) не срабатывает — поднимите простейший
локальный сервер без установки (модуль есть в Python из коробки):

```bash
cd путь/к/папке/с/index.html
python -m http.server
```

и откройте `http://localhost:8000`.

## Виды документов, префиксы и контрагенты

Кнопка **«Справочники»** в шапке открывает управление двумя списками:

- **Виды документов** — у каждого вида есть короткий **префикс**, который
  используется при сборке имени документа и имени файла вложения. Например,
  вид «УПД» с префиксом «УПД» + номер «2594» + дата «31.07.26» дают:

  ```
  УПД №2594 от 31.07.26
  ```

- **Контрагенты** — простой список названий.

Оба списка также можно пополнять «на лету»: в форме добавления документа при
выборе вида или контрагента внизу списка есть пункт «+ Новый...» — выбрав
его, можно тут же вписать новое значение, и оно попадёт в общий справочник
для всех следующих документов.

## Имя документа и имя файла — без ручного ввода

Раньше при добавлении файла нужно было вручную придумывать ему имя. Теперь
это не требуется: поле «Имя документа» — это просто номер, а полное
отображаемое имя (и, соответственно, имя файла на диске) собирается
автоматически по формуле:

```
{Префикс вида} №{номер} от {дата}
```

Если к документу прикрепляется несколько версий файла, к имени добавляется
номер версии: «УПД №2594 от 31.07.26 v2.pdf». Старые версии не
перезаписываются и остаются на диске, пока их не удалить вручную кнопкой в
карточке документа.

## Ограничения

- Работает только в Chrome / Edge / Opera (десктоп) — File System Access API
  не поддерживается Firefox и Safari.
- Разрешение на папку иногда приходится подтверждать заново при перезапуске
  браузера — это политика безопасности самого браузера, не приложения.
- Рассчитано на одного пользователя (без сети, без многопользовательского
  доступа).
