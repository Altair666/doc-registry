# Changelog

Версия и последний патч-ноут также видны прямо в приложении — кнопка
справа внизу («v2.5.2» и т.п.).

## v2.5.2 — 2026-08-05
- Убрано многоточие («…»), вылезавшее в крайнем столбце с кнопкой
  «Продвинуть».
- Логика ресайза изменена: теперь при перетягивании границы ширина
  забирается/отдаётся только у соседнего столбца справа (как в Excel) —
  общая ширина таблицы и её правая граница больше не меняются вообще,
  двигается только та граница, которую вы тянете.

## v2.5.1 — 2026-08-05
- Окончательно исправлен ресайз столбцов: раньше ширина таблицы
  вычислялась браузером через CSS (`auto`/`max-content`), которые
  разные движки трактуют по-разному в `table-layout:fixed` — из-за
  этого при перетягивании ЛЮБОГО столбца (включая средние) сдвигались
  все остальные. Теперь ширина таблицы — явная сумма ширин столбцов,
  которую JS сам пересчитывает при каждом движении мыши.
- Крайний столбец с кнопкой «Продвинуть» больше не ломается и не уезжает
  за экран — он был непрактично узким (60px), кнопка физически не
  помещалась; расширен до размера, где текст кнопки реально влезает
  целиком.
- В заголовках столбцов добавлены видимые полоски-разделители — сразу
  понятно, за какую границу можно тянуть, не нужно наводить мышь наугад.

## v2.5.0 — 2026-08-05
- Исправлен глючный ресайз столбцов реестра: раньше таблица была жёстко
  подогнана под 100% ширины блока, из-за чего при перетягивании одной
  границы браузер автоматически «утаптывал» остальные столбцы и граница
  дёргалась в сторону при захвате. Теперь таблица в собственном
  скролл-контейнере и растёт по факту суммы ширин столбцов — двигается
  только та граница, которую тянете, остальные столбцы неподвижны.
- Ширины столбцов теперь сохраняются (в `config.json`, в той же папке,
  что и остальные данные) и восстанавливаются при следующем открытии —
  раньше сбрасывались после обновления страницы.

## v2.4.1 — 2026-08-05
- Кнопка «Продвинуть →» в таблице реестра прижата к правому краю
  столбца, сам столбец сужен в 2,5 раза (150px → 60px).

## v2.4.0 — 2026-08-05
- Левая колонка с группами сужена на 20% — больше места под превью PDF.
- Один ползунок масштаба заменён на переключатель **«Список страниц» /
  «Крупно»**:
  - «Крупно» — как раньше: одна страница на всю ширину блока, без
    масштабирования, листается вниз;
  - «Список страниц» — компактный вид с ползунком масштаба, несколько
    страниц в ряд.

## v2.3.0 — 2026-08-05
- Заголовок «Новый документ» перенесён в одну строку с переключателем
  Один/Группа.
- В групповом режиме та же строка расширяется: переключатель, заголовок
  «Новый документ — группа», кол-во групп, кнопка выбора PDF и кнопки
  Отмена/Добавить документы — всё в одной шапке, а не раскидано по
  разным строкам.

## v2.2.0 — 2026-08-05
- Бейдж группы теперь показывает полное имя документа («УПД №2594 от
  31.07.26»), а не только вид.
- Добавлен масштабатор превью страниц PDF: страницы идут одна под
  другой (не мелкой сеткой), ползунок регулирует размер, максимум —
  одна страница на всю ширину блока, остальные листаются вниз.
- Рендер страниц стал в разы чётче (раньше рендерились сразу мелко,
  теперь — в высоком разрешении, масштаб только уменьшает картинку).

## v2.1.0 — 2026-08-05
- Степперы (кол-во групп, кол-во страниц у группы) переделаны: вместо
  кнопок +/- по бокам — стрелочки ▲▼ стопкой с одной стороны поля.
- Кнопка сброса (↺) перенесена вплотную к кнопке подтверждения (✓) в
  карточке группы.
- Бейдж группы теперь показывает выбранный вид документа (например
  «УПД»), а не просто порядковый номер — так проще понять, какой бейдж
  куда тащить, когда групп много.
- Поля в карточке группы расположены компактнее: вид документа, дата и
  номер — в одну строку (вид и дата — уменьшенным текстом), контрагент и
  сумма — во вторую строку.

## v2.0.1 — 2026-08-05
- Исправлена кнопка «Прикрепить PDF» в групповом режиме — не работала,
  потому что скрытое поле выбора файла оказалось вне кликабельной
  области кнопки. Переименована в «Выбрать файл», приведена к единому
  виду с остальными кнопками выбора файла.
- Добавлена визуальная реакция (подсветка при наведении и клике) на все
  кнопки выбора файла в приложении.

## v2.0.0 — 2026-08-05
- Цвет стадии в Справочниках теперь меняется через кружок с иконкой
  карандаша вместо длинного цветового поля.
- У всех «Выберите файл» — нормальные стилизованные кнопки в стиле
  приложения, с именем выбранного файла рядом.
- **Групповой режим добавления документов.** В окне «Новый документ» —
  переключатель Один/Группа. В групповом режиме окно разворачивается на
  весь экран: указываете количество групп, прикрепляете один общий PDF,
  для каждой группы заполняете поля (вид, номер, дата, контрагент,
  сумма, комментарий) и перетаскиваете её цветной бейдж на нужную
  страницу справа (с указанием, сколько листов подряд забрать). После
  подтверждения (✓) страницы уходят из общего пула, кнопка сброса (↺)
  возвращает их обратно. При добавлении исходный PDF автоматически
  нарезается на отдельные файлы по группам, с именами по тем же
  правилам, что и в одиночном режиме.
- Для группового режима подтянуты библиотеки `pdf.js` и `pdf-lib` —
  лежат локально в `js/vendor/`, подгружаются только при первом
  переключении в групповой режим, интернет не требуется.

## v1.9.0 — 2026-08-04

  значений — клик по значению фильтрует таблицу, несколько столбцов
  можно фильтровать одновременно.

## v1.6.0 — 2026-08-04
- Окно нового документа больше не закрывается и не стирается случайным
  кликом мимо — закрыть его можно только кнопкой «Отмена».

  «Стадии» в шапке убрана, теперь виды документов, контрагенты и стадии

## v1.5.0 — 2026-08-04
- Бейдж версии перенесён вниз-вправо и стал серым (раньше перекрывал
  заголовок «Реестр...» и был слишком заметным).
- Форма нового документа переверстана без сломанной вёрстки: модалка
  стала шире, порядок полей — сначала файл, затем дата (активируется

  числом), затем вид документа и номер в один ряд, ниже — контрагент во
  всю ширину.
- Выбор «+ Добавить новое» у вида документа и контрагента теперь
  превращает само поле (select) в текстовое прямо на месте — без
  отдельных блоков снизу, из-за которых раньше «прыгала» вёрстка.

## v1.0.0 — 2026-08-04
Первая версия: реестр учёта первичных документов на File System Access
API — работает без сервера, прямо в браузере (Chrome/Edge). Настраиваемые
стадии документооборота, версии файлов вложений (старые не
перезаписываются), история переходов по стадиям.
