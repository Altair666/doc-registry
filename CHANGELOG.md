# Changelog

Версия и последний патч-ноут также видны прямо в приложении — кнопка
справа внизу («v1.9.0» и т.п.).

## v1.9.0 — 2026-08-04
- Бейджи стадий стали разноцветными — цвет каждой стадии настраивается в
  Справочниках (палитра из 8 цветов, назначается автоматически новым
  стадиям, можно переопределить вручную).
- Столбцы таблицы реестра можно тянуть за границу заголовка, меняя
  ширину.
- Кнопка перехода переименована в «Продвинуть →», колонка под неё
  сужена под размер кнопки.
- Правый клик по заголовку **любого** столбца реестра (Документ, Вид,
  Контрагент, Сумма, Стадия, Файлы) открывает список встречающихся
  значений — клик по значению фильтрует таблицу, несколько столбцов
  можно фильтровать одновременно.

## v1.8.0 — 2026-08-04
- Переход в карточку документа теперь срабатывает только по клику на
  кнопку «Открыть →» — сама строка таблицы больше не кликабельна целиком,
  текст в её ячейках можно нормально выделять и копировать.
- Кружок со стрелкой заменён на обычную кнопку в стиле кнопок шапки.

## v1.7.0 — 2026-08-04
- Кнопка «Сохранить» в форме нового документа активна только когда
  выполнены все три условия: прикреплён файл, выбран вид документа,
  указан номер документа. Рядом — подсказка, чего не хватает.
- Поле «Имя документа (номер)» переименовано в «Номер документа».

## v1.6.0 — 2026-08-04
- Окно нового документа больше не закрывается и не стирается случайным
  кликом мимо — закрыть его можно только кнопкой «Отмена».
- Из карточки документа убрано: кнопка редактирования полей, вкладка
  «Прикрепить файл» отдельно от смены стадии, поле примечания к переходу,
  раздел «История стадий» (дублировал список файлов — там уже видно, на
  какой стадии что было загружено).
- Файлы теперь подписываются названием стадии («Получен», «На проверке» и
  т.д.) вместо номера версии (v1, v2...) — и в списке файлов, и в самом
  имени файла на диске.
- Стрелочка перехода в строке таблицы стала заметной кнопкой (обводка и
  цвет).
- Стадии документооборота перенесены в «Справочники» — отдельная кнопка
  «Стадии» в шапке убрана, теперь виды документов, контрагенты и стадии
  управляются в одном месте.

## v1.5.0 — 2026-08-04
- Бейдж версии перенесён вниз-вправо и стал серым (раньше перекрывал
  заголовок «Реестр...» и был слишком заметным).
- Форма нового документа переверстана без сломанной вёрстки: модалка
  стала шире, порядок полей — сначала файл, затем дата (активируется
  автоматически после прикрепления файла и сразу ставится сегодняшним
  числом), затем вид документа и номер в один ряд, ниже — контрагент во
  всю ширину.
- Выбор «+ Добавить новое» у вида документа и контрагента теперь
  превращает само поле (select) в текстовое прямо на месте — без
  отдельных блоков снизу, из-за которых раньше «прыгала» вёрстка.

## v1.4.0 — 2026-08-04
Добавлены версия приложения и патч-ноуты в шапке (кнопка слева вверху,
открывает список изменений).

## v1.3.0 — 2026-08-04
Виды документов упрощены до плоского списка (убрана отдельная графа
«Наименование» — теперь вид документа это и есть короткое обозначение,
например «УПД», «АКТ», «ТН»).

## v1.2.0 — 2026-08-04
- Код разбит по файлам: `index.html` (голая разметка), `css/style.css`,
  `js/config.js`, `js/storage.js`, `js/app.js`.
- Вид документа и контрагент — списки с возможностью дописать свой вариант
  (сразу сохраняется в общий справочник).
- Добавлен отдельный справочник (модалка «Справочники»): виды документов
  (с префиксами) и контрагенты.
- Имя документа и имя файла вложения теперь собираются автоматически
  (вид + номер + дата, например «УПД №2594 от 31.07.26») — подписывать
  файл вручную больше не нужно.

## v1.1.0 — 2026-08-04
В форму создания документа добавлена возможность сразу прикрепить файл,
не открывая карточку документа отдельным шагом.

## v1.0.0 — 2026-08-04
Первая версия: реестр учёта первичных документов на File System Access
API — работает без сервера, прямо в браузере (Chrome/Edge). Настраиваемые
стадии документооборота, версии файлов вложений (старые не
перезаписываются), история переходов по стадиям.
